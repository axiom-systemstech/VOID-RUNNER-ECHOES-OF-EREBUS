# VOID RUNNER: ECHOES OF EREBUS

A complete browser/PWA 3D sci-fi game built with TypeScript + Three.js.

## Run locally
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

The `dist/` folder is ready for Vercel. No server is required.

## GitHub + Vercel
1. Create a GitHub repository.
2. Upload this project.
3. Import the repository into Vercel.
4. Framework preset: Vite.
5. Build command: `npm run build`.
6. Output directory: `dist`.

The game is client-side and includes a service worker for offline/PWA caching after the first visit.

## Controls
PC: WASD, mouse, Shift, E, left click, Esc.
Mobile: touch joystick, FIRE, E and RUN buttons.

## Game
Story campaign with six missions, enemies, weapons, boss, multiple endings, secrets, trophies, local save, procedural station rooms, dialogue, particles, lighting, audio and responsive mobile controls.
